# Rendering (`src/render/`)

- `engine.ts`: renderer, scene, `THREE.Timer`, lights, texture loading, per-frame culling, `onStats` (fps + drawn chunks), `onProgress`. `engine.generate` starts the worker at once and streams events into the world; resolves `MapInfo` once fully built. `engine.terrain` = finished map only. Map options: `MAP_SIZE = 640`, `MAP_CELL = 2`.
- **Render pipeline** (`render/pipeline/`): `World.push(event)` stores the data in a live partial `Terrain` and queues jobs (`stages.ts` handlers). Job ranks (`RANK`): ground 0 → bases → roads → buildings → props (rocks, then trees; band order matters: cosmetic rng) → lights (street lights, gas station lights, landmarks, power, urban, wet mask) → finish. `World.step(BUILD_BUDGET_MS = 6, focus)` runs jobs each frame (`queue.ts`: by rank, then nearest focus; same key replaces). After jobs, `Culler.sync` registers new / removed / `userData.boundsDirty` meshes. A new map (`meta`) clears the old one (`RenderPipeline.begin` → every layer's `clear()`); `whenBuilt()` resolves when done. `World.build(terrain)` = load everything at once (`RenderPipeline.load` pushes every event kind).
- `world.ts`: owns all map meshes; layers `GroundLayer`, `RockLayer`, `RoadLayer`, `TreeLayer`, `BaseLayer`, `StreetLightLayer`, `BuildingLayer`, `UrbanLayer`, `LandmarkLayer`, `PowerLayer`, `ParticleSystem` (skill `particles`; GPU-instanced smoke/steam; meshes with a non-geometry extent carry `userData.cullBox`) (persistent groups). New layer ⇒ register: group in `World.group`, `layerGroups()`, `update` call, material in the per-frame fog list (`fogNear/fogFar/fogOrigin/gameRight/gameUp` uniforms), `RenderLayers` in `pipeline/stages.ts`.
- **Culling** (`culling.ts`): Three.js only does per-object sphere frustum culling. Map is split into 8-wide chunks (`CHUNK_CELLS` = 32 cells = 64 m; `ChunkGrid.key/center`, `groupByChunk`, `splitByChunk`). `Culler` tests each mesh's world Box3 against the frustum once per frame (buckets by 64 m ground cell). Water plane excluded (`userData.noCull`). **All map meshes must have identity transforms**: the main `Scene` has `matrixWorldAutoUpdate = false`, so anything that moves needs `updateMatrixWorld()`.
- **LOD**: `Culler` honours `userData.lodMin/lodMax/lodCenter` (camera distance to the chunk centre); `lodMaxCenter` measures the far limit from another point; a shadow pass uses `shadowLodMin/shadowLodMax` when set (trees: full mesh casts only within 90 m, low-poly stand-in beyond). Terrain chunks have 2 detail levels (`TERRAIN_LODS`); beyond 520 m 4×4 chunks draw as one **super chunk** (stride 4, then 8 beyond 1000 m, `SUPER_LODS`; distances × `terrainLodScale`). Chunk borders have skirts (`drop` attribute) that hide cracks. Far trees/rocks draw as camera-facing sprites (`billboard.ts`: offscreen bake per species/rock shape and 7 pitch columns, shaded with `Environment.spriteShade`).
- **Shader detail LOD** (`shaders/chunks/lod.glsl`): `surfaceDetail(p)` = 1 near → 0 between `DETAIL_START` / `DETAIL_END` (default 110 / 170 m; a shader may `#define` its own before the include). Beyond it the fine pattern isn't computed, the average colour is drawn (rail, sidewalks/plates/decal paving → `PAVING_AVG`, car-park markings, terrain 260/400 m, water 220/360 m, rocks). Road paint has its own fade (`MARK_FADE_*`, 140–220 m).
- Instancing: rocks (4 low-poly shapes), trees (merged vertex-coloured mesh per species, wind sway in the vertex shader), street lights (InstancedMesh per chunk and lamp type). Merged-mesh content (buildings, landmarks, power) uses `MeshData` (`render/buildings/geometry.ts`: `frame(x,y,z,yaw)`, `face`, `box`, `cylinder`, extras `aWin`, `aKey`) with the `building.vert/frag` shaders, a near mesh (`lodMax`) and a far mesh (`lodMin`); helpers `strut`, `frustum`, `disc`, `cone` live in `landmarks.ts`.
- Shaders are separate `.glsl` files imported via `vite-plugin-glsl`. Own chunks: `#include ./chunks/fog.glsl;` (with semicolon). Three's built-ins (`#include <tonemapping_fragment>`) are left for Three. GLSL 3 (WebGL2).
- Fog is custom (`fogNear/fogFar` scaled by camera distance in `World.update`). Map-edge haze (`fogdist.glsl`) fades by `max(|x|, |z|)` over the outer margin, high ground pulled nearer so range summits stay clear.
- `rtsCamera.ts`: edge-pan + WASD/arrows (Shift = fast), Q/E or middle-drag rotate, wheel zoom (25–650), focus follows terrain height, bounds = play area. Saved view `{ x, z, yaw, pitch, distance }` persists in `localStorage` (`wargame.settings`); `reset()` is only the fallback.
- The renderer draws the whole `Terrain` grid (play area + margin) the same way; only the camera is bounded to the play area.

## Adding a render layer
Class with `group`, `material` (if own shader), `build(terrain, grid)` (build job in `RENDER_STAGES`), `update(daylight/time)`, `clear()`; give every mesh `lodCenter` + `lodMin/lodMax`; far representation or hidden beyond a distance; lights via the `LightField` (skill `render-lighting`); shadow casters follow LOD levels (sprites need a low-poly `userData.shadowOnly`); bump `World.shadowEpoch` when what casts changes outside scene syncs.
